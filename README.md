# Variable Detective — Emoji Mystery

Play: https://hanhoco.github.io/emoji-mystery/

A Year 3 Scratch variable-tracing activity with 225 cells, sixteen programs,
per-cell scoring and an optional student-filled trace table.

## Use
Open the website in a modern browser, enter a learner code, predict the output
and apply its decoder colour. New learner starts a separate local record.

## Progress and privacy
Progress stays in the current browser profile. There is no account login,
central database, Moodle gradebook or cross-device teacher monitoring.
Use the same device/browser to resume, and export JSON or CSV results if needed.
Teacher tools and embedded answers are not access-controlled; this is a learning
activity, not a secure examination system. Do not enter sensitive personal data.
GitHub Pages hosting is subject to GitHub's privacy policy.

## Publishing
GitHub Pages serves the root of the default branch. The self-contained index.html
has no external runtime dependencies; .nojekyll disables Jekyll processing.
Only the static activity and this documentation are published, not the development
repository, local progress, student records or test reports.
